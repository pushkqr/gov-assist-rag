## 2. Key Architectural Insights

The benchmark logs and results highlight several advanced capabilities of the Function-Calling Supervisor Agent:

- **Adaptive Autonomous Retrieval:** The Agent isn't limited to a single vector search. When it deems the initial context insufficient, it autonomously iterates and fires off sequential searches with new keywords (e.g., executing multiple queries for the Steering Committee's roles).
- **Multi-document Synthesis:** The system successfully synthesizes and merges answers across disparate policy documents (e.g., cross-referencing NEP guidelines with AICTE approvals) without hallucinating.
- **Graceful Out-of-Scope Handling:** When tested with irrelevant queries (e.g., GST registration, passport procedures), the Agent accurately recognizes the limits of its indexed corpus and safely refuses to answer, ensuring zero hallucination.

## 3. Evaluation Methodology

Each case is blindly evaluated by an independent LLM Judge (`gemini-2.5-flash` at Temp 0.0) which compares the Agent's generated response against a hardcoded "Ideal Answer" ground truth.

- **Score 4-5:** The Agent successfully extracts the core facts and provides accurate context.
- **Score 0-3:** The Agent hallucinates, misses critical facts, or contradicts the documents.
